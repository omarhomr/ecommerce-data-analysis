## 📌 Dataset
- **Records:** 1,200
- **Columns:** 14 (OrderID, Date, Product, Quantity, UnitPrice, TotalPrice, OrderStatus, PaymentMethod, ReferralSource, CouponCode, ...)
- **Period:** Multi-year e-commerce transactions

## 🔑 Key Findings
- 💰 Total Revenue: **$1.26M**
- 📦 Top Product: **Chair** ($195,620)
- 📣 Top Channel: **Instagram** ($275,285)
- ⚠️ 41.4% of orders are Cancelled or Returned

## 🛠️ Tools Used
- Python (pandas, numpy, matplotlib, seaborn)
- SQL (MySQL)
- Excel / openpyxl
